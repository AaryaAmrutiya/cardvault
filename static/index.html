    Connect your data sources

    1. eBay: live prices, demand, liquidity

      Sign in at developer.ebay.com → Application Keysets → create a Production keyset. When asked about Marketplace Account Deletion, choose the exemption (this app doesn't store eBay user data). Copy the App ID and Cert ID.

      Optional: ask eBay for Marketplace Insights access to unlock real sold prices.

    2. PSA: grading population

      Your token goes in PSA_API_TOKEN. PSA must also approve your account for API access. If PSA shows as "awaiting approval", email collectors-apis@collectors.com and ask them to enable Public API access for your account.

    3. Add the keys

      Open cardvault\.env in VS Code, paste each key after its =, save, then close and re-open start.bat.

    Player data (Wikipedia, Wikidata, MLB Stats API) is free and needs no setup.
